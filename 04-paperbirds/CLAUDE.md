# paperbirds — правила проекта для архитектора

Ко-пилот инди-группы **paperbirds** (Нижний Новгород): ищет площадки и опен-коллы, готовит
черновики питчей, ведёт базу контактов. **Агент готовит — человек решает и отправляет.**
Цель — играть регулярно, тратя несколько часов в неделю; отсюда фильтр решений:
**что требует ежедневного ухода — плохо.** Отвечать PO **по-русски**.

> Свод правил для **любого** архитектора (Claude Opus · Kimi K3 · Qwen 3.8Max); имя историческое.
> Точка входа для не-Claude — `AGENTS.md`, устройство системы — `README.md`.
> **Здесь только то, что нужно в КАЖДОЙ сессии.** Остальное — по карте, открывать ПО ЗАДАЧЕ.

## ⛔ Золотые правила данных

База — главный актив: код перепишется за вечер, контакты арт-директоров и история переписки — нет.
Нарушение = дефект, а не вопрос стиля.

1. **Не выдумывать данные.** Не знаешь — `NULL` + `needs_verification`; выдуманный контакт хуже
   отсутствующего. **Пустая строка и пробелы — это «нет данных», а не значение.**
2. **У каждой записи `source_url` и `last_verified_at`.** Без источника запись бесполезна.
3. **Никакого автоотправления** (черновик → `outbox/`, шлёт человек) и **никакой накрутки**
   прослушиваний.
4. **Отбракованное не удаляем** (`irrelevant`, `not_eligible`) — иначе роутер молча съест
   настоящий опен-колл, и мы не узнаем.
5. **Скрейпинг вежливый:** задержка ≥2с, честный User-Agent, кэш, robots.txt.
6. **Секреты только в `.env`** (gitignored): репозиторий приватный, в БД личные контакты.

## Код и роли — коротко

**Стек зафиксирован** (Python/FastAPI/SQLite · React+Vite+antd · pytest/Vitest/Playwright),
**всё живёт только в Docker**, зависимости и агентские фреймворки не добавляем без спроса.
⚠️ `src/` и `tests/` **вшиты в образ** — без `docker compose build app` тесты гоняют старый код.
Сдача чего угодно = **зелёный `python3 scripts/gate.py`**. Код самодокументируемый, комментарии
по-русски и **ДЛЯ СЛЕДУЮЩЕЙ СЕССИИ** (контекст между сессиями теряется, комментарии = опора):
docstring «зачем», inline — ЗАЧЕМ/ПОЧЕМУ, а не пересказ кода, **префикс `AI:` на новых граблях**
(greppable-индекс `grep -rn "AI:" src/`; старые комментарии задним числом НЕ ретрофитим), метка
задачи (`# D1`). Конвенция перенята из проекта reports; детали — `docs/practices/код-и-тесты.md` §3.

- **PO — Владимир:** приносит задачу на уровне ЦЕННОСТИ, код не пишет и не читает.
  **Архитекторы** (Claude, Kimi K3, Qwen 3.8Max) равны, процесс один. **Кодер** — DeepSeek
  через Kilo CLI в автономном цикле, в `main` не мержит.
- **Поток:** задача PO → разбираюсь → **сам решаю, кто делает** → если кодер:
  **гейт → наряд → манифест → цикл → приёмка → `main`**. Декомпозиция и батчи — моя работа.
- **⛔ Наряд самодостаточен** (единственный канал к кодеру), **гейт пишется ДО наряда** и под батч.
- **⛔ Два прохода архитектора — потолок**; круги кодера внутри цикла бесплатны и не считаются.
- **⛔ После каждого наряда — строка расхода ЛИМИТА архитектора** против «сделал бы сам»
  (единица — недельный лимит, не деньги и не проценты: решение PO 11.08,
  `docs/наряды/README.md` §11). Отрицательную не сглаживать.
- Пробел в спеке — **спросить**, не додумывать про группу. Плохая идея — сказать до кода.
  **Качество выше токенов и времени.**
