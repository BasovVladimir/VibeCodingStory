# AGENTS.md — точка входа для не-Claude агентов

**Правила работы — в [CLAUDE.md](CLAUDE.md). Прочитай его целиком, он обязателен.**

Этот файл существует по технической причине: `CLAUDE.md` автоматически подхватывает только
Claude Code. Остальным нужен файл со стандартным именем, поэтому здесь — указатель, а не
второй свод правил. **Дубль правила = будущее нарушение**, поэтому дублей тут нет.

## Кому адресован

- **Kimi K3 и Qwen 3.8Max** (работают через Qoder) — они **равные архитекторы**, а не
  помощники Claude. Процесс, права и ответственность у всех троих одинаковые, личных зон нет.
  Для них `CLAUDE.md` — их собственный свод правил, имя файла историческое.
- **DeepSeek v4 Pro** (кодер, автономный CLI-цикл) — ориентир по стилю кода, тестам и границам.
  Но рабочее задание кодер получает **не отсюда, а из наряда**: наряд самодостаточен и является
  единственным каналом к исполнителю.

## Что важно знать про память

У каждого архитектора **своя** память. Читать чужую можно и полезно, **править — запрещено**.
Когда архитекторы работают параллельно в одном каталоге — `git pull` перед взятием задачи,
коммит и пуш только по просьбе PO: пуш уносит чужие незапушенные коммиты.

**У кодера памяти нет вообще.** Всё, что ему нужно знать, — в наряде. Если контекст остался
в голове архитектора, кодер его не получит и сделает неверно; это дефект наряда, а не
исполнителя.
