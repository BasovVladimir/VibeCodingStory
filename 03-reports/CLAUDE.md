# reports — правила проекта для архитектора

Личная инвест-система: отчётности + новости + цены + портфель копятся в БД и в заданных ритмах
превращаются в решения. **Распознавание и анализ — архитектор; хранение и расчёты — скрипты.**
Отвечать PO **по-русски** и **коллегиально**: выдача — рекомендация с обоснованием, не вердикт;
решение совместное. Дорожная карта — `docs/План и реализация.md`.

## ⛔ Запреты, которые дороже всего стоили

- **На S2 не ходим.** Тут тоже правило, и жёсткое, но я не могу светить его в публичном
  репозитории. **Серверы и `deploy/` — зона Claude.**
- **srv-nn (`<IP-СЕРВЕРА>`) — ОБЩИЙ сервер** (соседи paperbirds, scalpcal, mytrade): наше —
  только `/opt/reports` и юниты `reports-*`; правила подселения (обязательны к прочтению) —
  `~/Desktop/projects/paperbirds/docs/сервер-правила-подселения.md`.
- **Максимум ОДИН субагент на задачу.** «Несколько по очереди» — тоже нет; часто не нужен вовсе.
- **Коммит и пуш — ТОЛЬКО по просьбе PO:** каталог общий с Kimi/Qwen, пуш уносит чужие
  незапушенные коммиты. Перед взятием эмитента — `git pull`. Задача = своя ветка.
- **Слово-итог («под ключ», «дыр нет», «долг закрыт») — только ЧИСЛОМ «N из M» после запроса.**
  «Уже было» — запрещённое основание. Переименовал / перенёс / удалил → пересчитай охват.
- **Необратимое (`rm` боевых данных, зачистка) — отдельным заходом после слова-команды PO**
  и только после машинной сверки «всё есть на новом месте». Вопрос PO «удалить можно?» — не команда.
- **Долгие процессы — фоновой задачей** (`run_in_background`), не `sleep`; опрос фоновой
  задачи через `sleep` — то же нарушение.

## Данные: RAW → CANONICAL (инвариант архитектуры)

- **RAW** — `data/raw/{TICKER}/{период}_{стандарт}.json`, **в git**, истина «как в отчёте».
  **CANONICAL** — `db/reports.sqlite` (в gitignore, регенерится из RAW, потому и без alembic).
  Волатильное (цены, портфель, новости, вердикты) — только в персистентных таблицах БД.
- **⛔ Источник фактов — ТОЛЬКО первоисточники, руками и из веб-поиска не вписываем:** отчёты =
  PDF эмитента (born-digital МСФО+РСБУ; презентации не парсим), цены/облигации = MOEX ISS,
  ставка/инфляция/курсы = ЦБ РФ, портфель = T-Invest API. **Нет источника → поле пустое, и это видно.**
- Слои, таблицы, конвейер и скрипты — `README.md`; источник правды по скрипту — его docstring.

## Код, окружение, работа

⚠️ **Python — ТОЛЬКО через `uv`, венв проекта в `reports/` (не `.venv`):** любая команда
начинается с `source reports/bin/activate` (голого `python` в macOS-шелле нет). **Правку кода
без зелёного `pytest -q` не сдаём**, тесты в сеть не ходят. Подробности — `код-и-тесты.md`.

**Порог передачи кодеру — ОСНАСТКА ДЕШЕВЛЕ РАБОТЫ:** оснастка ≈ N (наряд + планка + приёмка +
черновик §7.2а) против работы ≈ K, **`K ≥ 2N` → отдаём**; числа пишутся в шапку наряда ДО старта.
Сдача — только зелёный гейт, красный = возврат без разбора. **Единица измерения — ЛИМИТ
архитектора, не деньги** (кодеры бесплатны): расход ≈ контекст × запросы, фаза = новая сессия.
**Качество выше токенов: экономим структурой работы, не срезая проверки.**

**Память архитектора — ТОЛЬКО состояние и правила поведения**, фактура вся в git. Про эмитентов
(метрики, выводы, вердикты) не пишем вообще: числа — `python scripts/card.py TICKER`, статус —
`card_status` → Anytype, решения — таблица `verdict`. **Чужую память (Kimi/Qwen) не править.**
