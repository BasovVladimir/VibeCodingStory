## Золотые правила

1. **Не выдумывай данные и цифры.** Не знаешь — `NULL`/пусто + пометка. Выдуманный уровень, ГО
   или винрейт хуже отсутствующего. **Всегда цифры > красивой истории.**
2. **Каждая рыночная величина хранит источник** (MOEX ISS / T-Invest / MyTrade L2 / расчёт).
   Число без происхождения непроверяемо.
3. **Никакой автоторговли и авто-отправки заявок.** Инструменты **готовят и подсвечивают** —
   решение и клик всегда за человеком.
4. **Один инструмент, один сетап, 1 контракт.** Размер — про нейрологию, не про деньги.
5. **Не добавляй зависимости без спроса** (stdlib по умолчанию). **Одна фича за раз**, запуск
   одной командой, проверяемо руками и тестами.
6. **Секреты — только в `.env`** (в `.gitignore`). Токены T-Invest берём из `reports/.env`.

## Код и тесты — коротко

**Всё всегда в Docker** (образ `scalping-tools`), портов не пробрасываем. Правку без зелёного
прогона **в контейнере** не сдаём: `docker compose run --rm --workdir /app/tools/<tool> app
python -m pytest`. Тесты в сеть не ходят, данные синтетические. Добавил тесты → **обнови
`TESTS.md`** (часть приёмки). Код самодокументируем: docstring «зачем», inline на неочевидном,
`AI:`-тег на новых граблях, метка наряда (`# BRIEF-2`), по-русски.
⚠️ **Зелёные тесты ≠ работающий инструмент:** слой, ходящий в сеть или БД, на приёмке дёргаем
**вживую**. Подробности и грабли — `docs/practices/код-и-тесты.md`.
