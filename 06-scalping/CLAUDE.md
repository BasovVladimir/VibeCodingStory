Менторство по **ручному скальпингу на Мосбирже**: научить PO стабильно торговать руками внутри
дня. **Ядро проекта — обучение и разбор**, а не код; инструменты (`tools/`) — подпорки под него.
Отвечать PO **по-русски**. Компас — `PLAN.md`, устройство репозитория — `README.md`.

> Свод правил для **любого** архитектора (Claude · Kimi K3 · Qwen 3.8Max), имя историческое;
> точка входа для не-Claude — `AGENTS.md`. **⛔ Здесь только то, что нужно в КАЖДОЙ сессии** —
> остальное открывать ПО ЗАДАЧЕ по карте. Правило, у которого есть дом в `docs/`, сюда не
> копируем целиком: дубль правила = будущее расхождение. **Исключение — выжимка в 3–5 строк
> со ссылкой на дом** там, где правило нарушается чаще всего (комментарии в коде): она не
> заменяет источник, а напоминает открыть его. Разошлись — правит источник, не выжимка.

## Золотые правила

1. **Не выдумывай данные и цифры.** Не знаешь — пусто + пометка. **Цифры > красивой истории.**
2. **Каждая рыночная величина хранит источник** (ISS / T-Invest / MyTrade L2 / расчёт).
3. **Никакой автоторговли.** Инструменты готовят и подсвечивают — клик всегда за человеком.
4. **Один инструмент, один сетап, 1 контракт.** Размер — про нейрологию, не про деньги.
5. **Секреты — только в `.env`** (в `.gitignore`); брокерские токены переиспользуются из
   соседнего проекта, а не заводятся заново.
6. **⛔ «Написал» ≠ «проверил».** Зелёные тесты ≠ работающий инструмент: слой, ходящий в сеть
   или БД, на приёмке дёргаем **вживую**, критерии наряда выполняю сам.
7. **⛔ Дефицит один — недельный лимит архитектора, не деньги** (кодер бесплатен). Экономим
   **структурой** («фаза = сессия», точечное чтение, вывод в файл), а не сокращением проверок.

Основания и боевые случаи — `docs/practices/уроки-агента.md`.

## Код и тесты

**Всё всегда в Docker** (`scalping-tools`), портов не пробрасываем. Правку без зелёного прогона
**в контейнере** не сдаём: `docker compose run --rm --workdir /app/tools/<tool> app python -m pytest`.
Тесты в сеть не ходят. Добавил тесты → **обнови `TESTS.md`** (часть приёмки).
Всё остальное — `docs/practices/код-и-тесты.md`.

**Комментарии обязательны** — PO код не правит, комментарий = опора для следующей сессии и для
кодера, у которого моего контекста нет:

- **Docstring модуля** с разделом «зачем/ПРОБЛЕМА»: откуда данные, куда пишет, как запускать.
- **Inline — ЗАЧЕМ и ПОЧЕМУ ИМЕННО ТАК**, а не пересказ кода: пересказ строки это шум.
- **⭐ Тег `AI:`** на новых граблях, инвариантах и боевых случаях — один `grep -rn "AI:" tools/`
  даёт всю карту опасных мест. ⛔ **Старое задним числом не ретрофитим** (иначе тег перестаёт
  значить «опасно»). Конвенция общая с `MyTrade` и `staffing`.
- **Метка наряда** (`# BRIEF-2`, `# PANEL-8`), **по-русски**, в плотности окружающего кода.

Развёрнуто, с примерами хорошего и шумного комментария — `docs/practices/код-и-тесты.md` §3.
